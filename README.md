# LifeManagementApp

LifeManagementApp on .NET MAUI -sovellus arjen hallintaan.

## Etusivu

- Näyttää nykyisen sään Open-Meteo API:n avulla
- Näyttää lämpötilan ja tuulen nopeuden
- Ilmoittaa kitesurf-kelistä, jos tuuli ylittää 5 m/s
- Näyttää kolme tärkeintä tehtävää

## Tehtävät

- Tehtävien lisääminen
- Prioriteetin valinta
- Eräpäivän asettaminen
- Lajittelu prioriteetin mukaan
- Lajittelu päivämäärän mukaan
- Tietojen tallennus SQLite-tietokantaan

## Muistio

- Muistiinpanojen kirjoittaminen
- Muistiinpanojen tallentaminen SQLite-tietokantaan

## Käytetyt teknologiat

- .NET MAUI
- XAML
- MVVM
- CommunityToolkit.Mvvm
- SQLite
- Entity Framework Core
- Open-Meteo API
- Dependency Injection

## Tekijä

Väinö Loitokari

## Kurssi

Client Side Programming
